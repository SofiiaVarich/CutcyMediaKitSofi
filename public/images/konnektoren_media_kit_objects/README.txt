Konnektoren Media Kit — Pink Animated Objects

All assets are PNG files with transparent backgrounds.

Suggested animations:
- butterflies: float, flap, rotate slightly
- hearts: pulse, bounce, sparkle
- bows/ribbons: gentle sway
- sparkles/stars: blink, scale, fade
- moon/planet/clouds: slow floating/parallax
- flowers/petals: falling/drifting
- bubbles/pearl: floating
- doodles/neon: glow/pulse
