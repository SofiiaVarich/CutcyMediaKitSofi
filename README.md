# Konnektoren MediaKit

A TypeScript/Next.js media kit for [Konnektoren](https://www.konnektoren.blog) and the [Konnektoren Help YouTube channel](https://www.youtube.com/@KonnektorenHelp).

## Development

```bash
npm install
npm run dev
```

The static production export is generated in `out/` with `npm run build`.

## Assets

All visual assets live in `public/images/`. Add new media to the relevant collection and use paths beginning with `/images/` in components.
